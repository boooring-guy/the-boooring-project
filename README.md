## 🎯 Project Goals

The Boooring Project is a **versatile learning hub** for modern application development. We build the same core product—a **Todo Application**—across every major platform to explore and compare implementation patterns, architectures, and tech stacks.

- **Learn by Doing**: A practical blueprint for building cross-platform experiences.
- **Platform Agnostic**: Identical logic implemented in Web, Mobile, and Backend.
- **Infinite Complexity**: Start with a Todo baseline, then scale with AI, advanced UX, or experimental features.

---

## 📁 Project Structure

This is a **uni-repo** where each platform implementation resides in its own directory:

- **[Backend (Express)](./backend/express)**: The core API service built with Express.js and Bun.
- **Web (Coming Soon)**: Planned Next.js/React implementation.
- **Native (Coming Soon)**: Planned React Native/Expo implementation.
